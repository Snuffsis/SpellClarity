# Independent addon responsibilities

| File | Owner/responsibility |
| --- | --- |
| Bootstrap.lua | Private namespace, safe text/number access, conflict guard |
| Locale.lua | English fallback and Swedish labels |
| Format.lua | Complete known Equip bonuses and comparison labels |
| SpellData.lua | Build-pinned spell scalar data |
| SpellDetails.lua | Supported damage, healing, periodic, absorb and weapon calculations |
| NativeTooltips.lua | Native tooltip hooks, transactional edits and Shift refresh |
| Main.lua | Login/addon lifecycle, SpellClarityDB and language command |

The TOC defines the load order. No assets, globals, databases or libraries are
required from Aevum. Conflict detection only asks whether its tooltip addon or
the older ForeverUI/ForeverSkin variants are loaded. It then pauses processing.

Keep native frames, fonts and colors. No skins, item counts, cursor following or
new settings panel are part of SpellClarity. Preserve unknown/protected text and
the 48-row ceiling. English equipment descriptions are parsed; Swedish is a label
option, not a localized-client parser. Keep saved language choices intact.

Data supports 1.60.1.70338. Do not merely change the build number to enable estimates
on another client. Verify formulas/scalars and update source attribution together.
The existing dataset and provenance are retained, not regenerated by release jobs.

Tests load the actual root TOC in isolated globals without Aevum. Release validation
also loads the packaged runtime, tests exact file contents, and guards publication.
